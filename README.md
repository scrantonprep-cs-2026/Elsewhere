# Elsewhere
Elsewhere is a 2D pixelated, dark-fantasy themed platformer where there is magic and tons of action.

## How to Run
 
1. Install Python 3.
2. Install the libraries: `pip install -r requirements.txt`
3. Run the project: `python src/main.py`
 
## Folders
 
- src/ - Python code
- assets/ - images, sounds, maps, data files
- docs/ - documentation and plans
- prototypes/ - test code
 
## How We Work
 
- main must always run without errors.
- Every change gets its own branch, named like feature/double-jump.
- Changes reach main only through a pull request approved by one teammate.
- Never commit directly to main.
